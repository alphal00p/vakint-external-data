# Five-loop symbolic reduction

This pack contains 640 unevaluated terminal integrals and the native RustRed
application for the recorded campaign scope. Each `masters/P*/graph.dot`
contains its complete numerator, masses, powers and explicit loop basis.
The scalar model is `model.json`. No numerical coefficients are supplied.

The selected prepared cache contains two strict-complete training roots and
25,086 intermediate records in one native gzip file. Its original build remains
a pilot; a later Root decision selects that exact artifact as the completed
fallback after a separate three-root trial exhausted its time budget.
See [cache/README.md](cache/README.md) for producer, consumer and failure scope.

The exact signed-index identity is recorded in `manifest.json`; P-numbers are
display names only. `coverage.json` describes recorded entry predicates. Cache
completion does not enlarge those predicates or prove global campaign closure.
